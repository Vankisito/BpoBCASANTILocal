# Descargar la plantilla de cobranza

Para preparar correctamente el archivo de cobranza, el sistema ofrece una **plantilla descargable** con el formato esperado.

## Dónde se descarga

1. Abre el asistente **Cobranza Diaria** del área Gestión de Seguros.
2. Selecciona la **Aseguradora** y el **Ramo** (vida o gmm).
3. Usa el botón **Descargar plantilla**.

## Formato

- La plantilla se entrega como un archivo **CSV**.
- Los **encabezados** de columna coinciden con los que el sistema espera al procesar.
- La plantilla se genera según la aseguradora y el ramo seleccionados, por lo que siempre coincide con la validación de estructura.

## Por qué usar la plantilla

- Garantiza que el archivo pase la validación de **columnas requeridas**.
- Evita errores de estructura al importar.
- Sirve de referencia de los formatos de fecha y montos esperados.

## Notas

- La descarga no requiere adjuntar un archivo; se genera directamente.
- Si el formato difiere (p. ej. columnas distintas), el proceso lo rechaza al validar la estructura.
