# Coberturas

Las **coberturas** de la póliza se eligen entre las que **ofrece el producto** seleccionado. Se dividen en básicas y adicionales.

## Tipos de cobertura

| Tipo | Descripción |
|---|---|
| **Cobertura Básica** | La cobertura principal del producto. Se elige una por póliza. |
| **Coberturas Adicionales** | Coberturas opcionales/extras contratadas. Se pueden elegir varias. |

## Cómo se capturan

1. Selecciona el **producto** (ver *seleccionar-producto*).
2. En el campo **Cobertura Básica**, elige la cobertura base entre las que ofrece el producto.
3. En **Coberturas Adicionales Contratadas**, marca las adicionales deseadas.

## Reglas

- Las opciones disponibles quedan filtradas por el **producto** elegido: solo se muestran las coberturas que ese producto ofrece.
- Si cambias de **producto**, las coberturas elegidas se **limpian** (dejan de pertenecer al producto anterior).
- El tipo de cobertura también puede capturarse como dato (Estándar, Accidentes, Invalidez) según el ramo.

## Notas

- La selección estructurada de coberturas se apoya en el catálogo de atributos de producto (Cobertura Básica / Adicionales), de modo que el selector siempre muestra solo lo válido.
- Existe además un campo de texto libre para **coberturas adicionales como notas** (de la carga de cartera), separado de la selección estructurada.
